[![Android CI](https://github.com/RokishiSensei/roxy-notebook/actions/workflows/android.yml/badge.svg)](https://github.com/RokishiSensei/roxy-notebook/actions/workflows/android.yml)

一个按 **首字母 A–Z 自动分组** 的英语生词本 Android App。记录不会的单词，填写 **词性 / 中英文释义 / 例句 / 标签 / 笔记**，可以用 **自己配置的 AI 接口** 一键查询补全，也可以直接和 AI 聊单词、句子、语法，最后用记忆卡片和测验把它们背下来。

- **现代 UI**：Material 3（Material You 动态取色）+ Jetpack Compose，大圆角、大字重的 Expressive 风格
- **适配 Android 16 (API 36) 与 Android 17 (API 37)**：`compileSdk 37` / `targetSdk 37`，全屏 edge-to-edge，预测返回手势，自适应布局
- **自带 AI，但接口由你自己提供**：支持 OpenAI 兼容（OpenAI / DeepSeek / 通义 / Kimi / Ollama / LM Studio…）、Anthropic Claude、Google Gemini，可自定义地址、密钥、模型、温度、超时和系统提示词
- **本地优先**：单词、分组、聊天都保存在设备上，可导出 JSON / CSV / 纯文本备份
- **244 个单元测试**，lint 0 项

> 仓库地址：<https://github.com/RokishiSensei/roxy-notebook>
>
> ```bash
> git clone https://github.com/RokishiSensei/roxy-notebook.git
> ```

## 一、功能

| 模块 | 能力 |
| --- | --- |
| 四级词库 | 设置里新增「**添加四级英语单词**」：把内置的 331 个四级核心词汇一键加入「🎓 四级核心」分组，已存在的自动跳过，可反复点补齐；词库是 `assets/wordpacks/cet4-core.json`，纯 JSON 想加词直接改文件 |
| 重复规则 | **同一分组内不允许重复单词，不同分组之间允许同一个单词**（例如 bank 可以同时在「四级核心」和「阅读生词」）；再次导入同组同词会合并义项；删除分组只删除「只属于该组」的词条，不会把重复词搬到未分组；**复制出的词条从零开始学习**（不继承星级/掌握度/复习次数），原词条不受影响 |
| 复制词条 | 多选后新增「**复制到分组**」；「移动分组」弹窗里也有「同时复制一份到…」，可以把同一个词放进两个分组 |
| 自定义背景 | 设置 → 外观：**主页背景**和**干净浏览背景**是两套独立设置，各自可选 6 种底色 + **从相册选一张图片**（图片会复制进应用内部，原图删掉也不影响）、各自用 **背景浓度 0–100** 滑杆 + 5 个快捷档位微调，点击 **「保存」按钮** 立即落盘并给出提示，还能一键「复制另一套」；顶部有总开关。浓度会同时驱动背景层自身 alpha 和 Material Surface 的半透明程度（100% 时 surface 降到 0.28，图片真正透出来）；所有背景设置都用 `commit()` 同步写盘 |
| 干净浏览 | 选中某个分组后，列表上方出现一整条 **「📖 干净浏览『分组名』」按钮**（显示词条数），点它进入**干净浏览**：只剩单词、音标、词性和释义的纯净排版。**所有控件都在底部工具栏**（可横向滑动，4 秒自动隐藏、点任意处唤回）：🔍 分组内搜索（匹配单词/音标/中英释义/标签/笔记）、**右侧 A–Z 索引条**（和主页一致：点字母直接滚动跳到该首字母的词，不筛选、不改变列表）、**↩ 续读**（跳回上次读到的那一条，按分组分别记忆）、⇅ 排序（**A–Z / 最新在前 / 最早在前**）、字号 80%–180%、🎨 背景快捷入口、✕ 退出。排序方式、字号、阅读位置都会记住。干净浏览是**二级页面**，按系统返回键即返回生词本 |
| 生词本 | 列表**始终按首字母 A–Z 分组**（顶部切换行已移除，右侧保留 A–Z 索引条 + 工具栏字母跳转弹窗）；**分组**和**日期**都作为筛选条件叠加在字母分组之上；搜索（单词 / 音标 / 中英释义 / 标签 / 笔记 / 来源）；筛选（重点词 ⭐、新词 / 学习中 / 熟悉 / 已掌握）；点词条编辑、长按进入多选 |
| 词条排版 | 单词行分三层显示：① 单词 + 音标（**朗读 / ⭐ 按钮固定宽度，所有行严格对齐**）；② 词性徽章 + **完整中文释义（最多 4 行，不再截断）** + 右侧**添加日期时间**；③ 英文释义；④ 掌握度、分组、标签横向滑动条；⑤ 笔记预览。另提供「紧凑列表」模式 |
| AI 批量导入 | 生词本右下角「添加生词」**上方新增 ✨ 按钮**：粘贴或选择任意格式的单词文件（txt / csv / md / json，甚至直接复制别家的词表），交给 AI 整理成 App 格式；**先预览再入库**，可逐条勾选、识别重复词、显示分组与标签，确认后才写入 |
| 日历查看 | 工具栏新增 **📅 按钮**：弹出月历，有词条的日期高亮并显示条数，点某天只显示当天添加的单词（仍按 A–Z 排列），再点一次或点横幅 ✕ 取消；下方还有「最近有记录的日期」快捷列表 |
| 自定义分组 | 新建 / 重命名 / 删除分组，可选 12 种图标 + 6 种颜色；分组芯片带词条计数；「未分组」自动归类；删除分组不会删词条（回到未分组）；设置页与统计页都有分组分布 |
| 多选批量操作 | 点标题栏的 ✓ 图标或长按任意词条进入多选，支持**全选 / 取消全选**，可批量**删除**（带二次确认）、**标记 / 取消重点**、**移动分组** |
| 添加 / 编辑 | 英文单词或词组、音标、**多词性多释义**（16 种词性）、中文释义、英文释义、例句、来源、标签、笔记、掌握度、分组；也可在编辑页里用 **AI 查询** 一键补全 |
| AI 查词 | 在编辑页输入英文 → 点「AI 查询」→ AI 返回**音标、全部词性义项（多义词会列全）、英文释义、例句、易错提示、标签**，自动填入表单（不覆盖你已填的内容）；返回 JSON 解析失败时会退回宽松文本解析，也可以查看模型原始回复 |
| AI 问答 | 底部新增「AI 问答」标签页：像聊天一样问单词用法、近义词区别、句子语法、让它改英文表达；支持快捷提问、多轮上下文、「正在思考」打字动画、一键复制回复 |
| 多会话聊天 | 可**新建多个对话**（自动用第一句话命名），左上角抽屉查看**历史对话**列表（轮数 + 相对时间 + 摘要），支持切换、重命名、单条删除、清空当前对话；设置里可导出全部对话为纯文本 |
| 复习 | 记忆卡片（正面可设为英文或中文）；「查看释义 → 忘了 / 记住了」间隔重复调度；**今天该背 / 只背重点 / 全部词随机抽背 / 今天新增的词 / 按分组随机抽背**五种入口；今日目标双环进度 |
| 测验 | **独立的测验设置页**：出题范围（全部 / 待复习 / 重点词 / 今天新增 / 指定分组）× 题型（中译英选择 / 英译中选择 / 看中文拼写 / 混合出题）× 题目数量（4–50）；答题即时反馈并显示例句；**结果页有正确率、逐题明细（含你答错的内容）、一键「重练错题」** |
| 发音 | 系统 TTS 朗读（支持 0.6x 慢速），列表、卡片、编辑器里都能点 |
| 设置 | 主题、Material You 取色、紧凑列表、每日目标、卡片方向、自动朗读、触感反馈、排序、**AI 接口配置与连接测试**、JSON / CSV 导入导出、AI 对话导出、清空数据 |
| 自适应 | 手机底部导航栏（4 个标签：生词本 / 复习 / AI 问答 / 设置）；≥600dp（平板 / 折叠屏展开 / 横屏）自动切换为侧边 NavigationRail |
| 单元测试 | 106 个纯 JVM 测试：字母分组、排序、草稿校验、词性映射、CSV 读写、日期区间、**日历（月份网格对齐 / 跨年翻月 / 按天分组 / 添加时间文案 / 分组字母序）**、**分组去重规则（同词跨组 / 同组拒绝 / 复制 / 移动并复制 / 删除分组 / 旧数据清理 / 四级词库解析）**、**两套背景配置的独立性与持久化、透明度换算**、**干净浏览排序/搜索、A–Z 索引跳转定位、阅读位置持久化、分组哨兵映射（未分组筛选）**、AI JSON 解析（含代码块 / 花括号嵌套 / 非 JSON 兜底）、AI 结果合并、测验出题与选项唯一性、错题重练、聊天会话模型、**导入格式（Robolectric 跑真实 SharedPreferences：Tab/竖线/单列、带/不带表头、括号英文释义与例句、重复合并、导出再导入）、批量导入解析（JSON 各种形状 + 逐行兜底）** |

## 二、配置 AI 接口

打开 **设置 → AI 学习助手 → AI 已连接 / 未配置**（或底部「AI 问答」标签页右上角齿轮）。

| 字段 | 说明 |
| --- | --- |
| 接口类型 | `OPENAI`（OpenAI 兼容，最常用）、`ANTHROPIC`（Claude）、`GEMINI`（Google） |
| API 地址 | 可填完整地址（`https://api.deepseek.com/v1/chat/completions`），也可只填到 `/v1`，App 会自动补全路径 |
| API Key | 本地保存，导出数据时**不会**包含；本地模型可留空 |
| 模型名称 | 手填，或点「**获取在线模型**」让 App 请求接口并列出该 Key 可用的全部模型，在弹窗里搜索、点选即可 |
| 温度 / 最大长度 / 超时 | 查词建议温度 0.2–0.4；超时默认 60 秒 |
| 提示词 | 查词 / 聊天 / 批量导入三套提示词都可编辑，可一键恢复默认 |

### 多套配置档

设置页顶部是**配置档列表**，可以保存多套接口并一键切换：

- 「＋ 新增」创建空白配置；点任意一条即切换为当前使用（标「使用中」）
- 每条支持**重命名**、**复制**（做变体时不会丢原配置）、**删除**（至少保留一条）
- 左侧圆点表示是否已填好地址（绿色 = 可用）
- 典型用法：一套便宜的模型专门查词，一套能力强的模型专门做批量导入，随时切换互不影响

### 获取在线模型

点「**获取在线模型**」会请求接口并列出该 Key 可用的全部模型，弹窗里可以搜索过滤、标出当前使用的模型：

| 接口类型 | 请求 | 解析字段 |
| --- | --- | --- |
| OpenAI 兼容 | `GET {base}/v1/models` | `data[].id` |
| Anthropic | `GET {base}/v1/models` | `data[].id` / `name` |
| Gemini | `GET {base}/v1beta/models?pageSize=200` | `models[].name`（自动去掉 `models/` 前缀） |

结果排序去重后展示。某些自建网关没有实现 `/models`，此时会明确提示「该接口不支持列出模型（HTTP xxx）」，手动填模型名即可。

常用地址示例：

| 服务 | API 地址 | 模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| Ollama（电脑本地） | `http://192.168.x.x:11434/v1` | `qwen2.5:7b` |
| LM Studio（电脑本地） | `http://192.168.x.x:1234/v1` | 任意已加载模型 |

> 填好点「**测试连接**」，成功会提示模型回显内容，失败会给出 HTTP 状态码和原因。
> 国内直连 OpenAI 一般需要代理；Android 默认禁止明文 `http://`，局域网自建服务请自行配置网络安全白名单。
> 不配置 AI 时，AI 相关按钮会隐藏或引导去设置，其余功能完全离线可用。

## 三、直接安装

已构建好的安装包：

| 文件 | 说明 |
| --- | --- |
| `dist/Roxy-1.16.3-debug.apk` | 调试包，包名 `com.lexi.wordbook.debug`，可直接安装，与 release 可共存 |
| `dist/Roxy-1.16.3-release.apk` | 正式包，包名 `com.lexi.wordbook`，已用 `keystore/lexi-release.jks` 签名，体积更小 |

手机上打开「设置 → 应用 → 特殊权限 → 安装未知应用」允许文件管理器安装，然后点开 APK 即可。用 adb 安装：

```bash
adb install -r dist/Roxy-1.16.3-release.apk
```

> TTS 朗读依赖系统的文字转语音引擎（多数国行 ROM 需要装「Google 语音服务」或厂商 TTS）。没有引擎时其余功能不受影响。

## 四、从源码构建

### 环境

| 组件 | 版本 |
| --- | --- |
| JDK | 21（`keytool`/Gradle 用；JDK 17 亦可） |
| Android SDK Platform | **API 37**（`platforms;android-37.0`）+ API 36 可选 |
| Android SDK Build-Tools | 37.0.0 |
| Gradle | 9.8.1（工程内已带 `gradlew`） |
| Android Gradle Plugin | 9.4.1 |
| Kotlin | 2.4.21（Kotlin 支持由 AGP 内置） |
| Compose BOM | 2026.09.00 + material3 1.4.0 |

### 命令行

```bash
# 1) 指向本机 SDK（若用 Android Studio 打开则自动生成）
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 2) 构建
./gradlew :app:assembleDebug        # 产物 app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:assembleRelease      # 产物 app/build/outputs/apk/release/app-release.apk
./gradlew :app:testDebugUnitTest    # 106 个单元测试
./gradlew :app:lintDebug            # 静态检查（当前 0 项）
./gradlew :app:installDebug         # 直接装到已连接设备
```

Windows 上如果工程路径含中文，`gradle.properties` 里的
`android.overridePathCheck=true` 已经帮你关掉了 AGP 的路径检查。

> 注意：本机 `gradle/wrapper/gradle-wrapper.properties` 里的 `distributionUrl` 指向了
> 本机已解压的 Gradle 9.8.1（为了在离线/慢网环境下不重复下载 145 MB）。
> 换到别的电脑上，请把这两行改回官方地址（文件里有注释说明），或直接用 Android Studio 打开：
>
> ```properties
> distributionUrl=https\://services.gradle.org/distributions/gradle-9.8.1-bin.zip
> distributionSha256Sum=dce76f55f8e251a3a1f130eb120f30b3d271de2b76c9b0729d316b5a1b6dc01f
> ```
>
> 也可以完全不用 wrapper，直接用本机 Gradle 9.8.1：`gradle :app:assembleDebug`。
>
> 另外 `local.properties` 里的 `sdk.dir` 也是本机路径，Android Studio 会自动重写。

### Android Studio

直接用 Android Studio 打开工程根目录即可（需要支持 AGP 9.4 的版本）。首次同步会下载依赖。

### 签名

`keystore/keystore.properties` 保存 release 签名信息：

```properties
storeFile=keystore/lexi-release.jks
storePassword=lexi2026
keyAlias=lexi
keyPassword=lexi2026
```

想换成自己的密钥：删掉这个文件并重新执行 `assembleRelease`（会自动回落到 debug 签名），
或用 `keytool` 生成新密钥后修改此文件。**上架应用市场请务必换成自己的密钥并妥善保管。**

## 六、AI 请求细节

- 只依赖 `HttpURLConnection` + `org.json`，**没有引入任何网络库**，release 包 1.45 MB。
- 三种协议分别组包：OpenAI 用 `messages` + `Authorization: Bearer`；Claude 用 `system` + `messages` + `x-api-key` + `anthropic-version`；Gemini 用 `systemInstruction` + `contents` + `x-goog-api-key`。
- 解析回复时依次尝试 `choices[0].message.content` / `content[].text` / `candidates[0].content.parts[].text`，再退回 `output_text` / `response` / `result` / `text` / `answer` / `message`，兼容自建网关。
- 查词时系统提示词要求模型只返回 JSON；解析器会去掉 ```json 代码块、跳过前后废话、按花括号配对（正确处理字符串内的 `{}`）取出对象。解析失败时用正则抓音标 + `n. 释义；释义` 形式的行做宽松解析，保证再差也能用。
- 合并策略：AI 结果**不覆盖**你已经填过的单词拼写、标签和笔记，多义词会作为多条释义追加。
- 聊天只带最近 12 轮上下文，避免 token 爆炸。

## 八、导入格式与 AI 批量导入

### 6.1 表格导入（设置 → 数据 → 从文件导入）

一行 = 一个词条，**推荐用 Tab 分隔**；也认 `|`、`｜` 和逗号（逗号会按 CSV 引号规则解析）。表头可写可不写。

```
word	phonetic	senses	tags	group	note	status
diet	/ˈdaɪət/	n. 日常饮食；n. 规定饮食；v. 节食	健康 减肥	饮食	注意区分 die	NEW
```

- `senses` 单元格用 `；` 分隔多个义项，每项写成「词性 释义」；英文释义放括号里，例句写 `例: …`
- 没有表头时按上面的列顺序解析；只有两列时按「单词 | 释义」处理
- `group` 里写分组名，不存在会**自动创建**
- 再次导入同一个单词会**合并义项**而不是产生重复条目
- 想快速记几个词，一行 `word|释义` 就够
- 设置页可以「**导出导入模板**」，拿到标准表头照着填

### 6.2 AI 批量导入（生词本右下角 ✨）

适合把**别的软件/文件里的词表**搬进来：

1. 点「添加生词」上方的 ✨ 按钮
2. **粘贴剪贴板**或**选择文件**（txt / csv / md / json 都能读）
3. 点「交给 AI 整理」——内容多时会自动分段发送（每段约 40 行），带进度显示
4. AI 返回后进入**预览页**：逐条显示单词、音标、全部义项、分组、标签，可以勾选/取消，自动标出词库里已有的「已存在」条目
5. 「跳过重复」开关默认开启；确认后点「导入生词本」才真正写入

没有配置 AI 时按钮会引导去设置；AI 返回非 JSON 时会自动退回逐行解析（支持 `1. diet /ˈdaɪət/ n. 日常饮食`、`word|n.|释义`、`word 释义`、`- word v. 释义` 等写法），所以即使模型不听话也能用。整理提示词可以在界面里直接改。

## 应用图标

图标由 `tools/make_icon.py`（Pillow）从 `tools/src/roxy-source.png` 生成。整条流水线是可重跑的：

```bash
python tools/make_icon.py     # 重新生成所有图标尺寸
```

处理步骤：

1. **裁切**：以人物头部为中心取正方形（约 1.55 倍头高），保留头发、脸、领口与肩部
2. **背景处理**：把四角压成模糊的深蓝雾面（`HAZE` / `HAZE_DEEP`），保留画面中心的人物细节
3. **边缘压暗**：径向压暗到 9,17,40，让明亮的脸在小尺寸下也能跳出来
4. **冷色调色**：压红、提蓝 + gamma 提亮中间调 + 轻微 S 曲线增加通透感
5. **导出**：自适应图标三层 + 各密度方形/圆形回退

| 输出 | 用途 |
|---|---|
| `mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher_foreground.png` | 自适应图标前景（画稿已缩进 66% 安全区） |
| `mipmap-*/ic_launcher_background.png` | 自适应图标背景（深蓝渐变，和雾面同色系） |
| `drawable/ic_launcher_monochrome.xml` | 主题图标（Android 13+）单色剪影，矢量 |
| `mipmap-*/ic_launcher.png` + `ic_launcher_round.png` | API 26 以下的方形 / 圆形回退 |
| `tools/icon-preview.png` | 256px 预览 |
| `tools/icon-sizes.png` | 96 / 72 / 48 / 36px 缩略对照，用来检查小尺寸辨识度 |

> 想换图：把新图覆盖到 `tools/src/roxy-source.png`（或改 `SRC` 常量），再跑一次脚本即可。裁切框、雾面强度、调色参数都在脚本顶部，注释里有说明。
